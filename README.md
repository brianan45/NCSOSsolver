This repo contains solvers that rewrite polynomials as sum-of-squares using semidefinite optimization, plus required helper functions.

Polynomial solvers include:
unconstrained commutative,
constrained commutative,
unconstrained complex commutative,
unconstrained non-commutative,
constrained non-commutative,
